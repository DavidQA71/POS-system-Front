### 💻 **POS System - Frontend**

Frontend del sistema de punto de ventas desarrollado con **React** (Vite) y **Typescript**.

---

## 📁 Estructura del proyecto

Este frontend se conecta con el backend disponible en:  
🔗 https://github.com/DavidQA71/POS-system-Backend

---

## ⚙️ Requisitos previos

Asegurate de tener instalado:
- Node.js (versión 18 o superior)
- npm

---

## 🚀 Cómo levantar el proyecto

1. ### Cloná este repositorio:

   git clone https://github.com/DavidQA71/POS-system-Front.git

2. ### Ejecutar:
```
npm run dev

```
